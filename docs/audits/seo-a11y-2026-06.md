# SEO & accessibility audit — June 2026

_Empirical pass over the production build (`next build` + `next start`), every
HTML route checked with the script below. This is the dated record for the
launch checklist; re-run after big structural changes._

## What was checked, per route (23 routes)

- exactly one `<h1>`
- every `<img>` has an `alt` attribute
- `<title>` present (per-page, via the title template)
- `rel="canonical"` present
- `meta name="description"` present (spot-checked)
- JSON-LD present on the homepage (NGO + WebSite `@graph`)

## Results

| Check                             | Result                                                                          |
| --------------------------------- | ------------------------------------------------------------------------------- |
| One `<h1>` per page               | ✅ 23/23 — `/intro` had none (full-screen film); **fixed** with an `sr-only` h1 |
| `<img>` alt attributes            | ✅ no images without `alt` anywhere                                             |
| Titles + canonicals               | ✅ 23/23                                                                        |
| Meta descriptions                 | ✅ present on sampled pages (all pages use `buildMetadata` or the root layout)  |
| JSON-LD                           | ✅ NGO + WebSite graph on the homepage; FAQPage schema on the FAQ page          |
| robots.txt / sitemap.xml          | ✅ `app/robots.ts`, `app/sitemap.ts` (all routes listed)                        |
| RSS + auto-discovery              | ✅ `/feed.xml` valid; `alternates.types` site-wide                              |
| `html lang`, skip link, landmarks | ✅ `lang="en"`, skip-to-content link, `<main id="main">`                        |
| `security.txt`                    | ✅ `/.well-known/security.txt` (RFC 9116)                                       |

## Known limitations of this pass

- No browser-based checks (contrast ratios, focus order, reduced-motion
  behavior) — this environment is curl-only. Run Lighthouse + axe in a real
  browser before launch; that item stays on the README launch checklist.
- Heading _order_ below h1 wasn't machine-checked, only h1 presence/count.

## How to re-run

Build + start, then for each route count `<h1>`, `<img` without `alt=`,
`<title>`, and `rel="canonical"` occurrences (see the audit command in the PR
history, commit adding this file).
